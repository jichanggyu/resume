# UC25 – ACS로부터 작업 명령 수신 (Receive Task Command from ACS)

## 개요

| 항목 | 내용 |
|------|------|
| **유즈케이스 ID** | UC25 |
| **유즈케이스 명** | ACS로부터 작업 명령 수신 |
| **관련 기능 요구사항** | SR7. 외부 시스템 연동 (ACS) |
| **주 액터** | ACS 시스템 (외부 제어 시스템) |
| **목적** | 상위 시스템(ACS)으로부터 작업 명령을 수신하고 로봇 제어 흐름에 반영한다. |

---

## 사전 조건

- ACS와의 네트워크 연결이 확보되어 있어야 한다.
- 명령 데이터 형식(작업 ID, 시나리오 ID 등)이 사전에 정의되어 있어야 한다.
- FastAPI는 외부 요청을 수신할 수 있는 엔드포인트를 제공해야 한다.

## 후 조건

- 수신된 명령이 유효성 검사를 거쳐 ROS2에 전달된다.
- 해당 명령을 기반으로 로봇이 작업을 수행하거나 작업 시나리오가 전환된다.

---

## 기본 흐름

1. ACS는 TCP 또는 소켓 통신으로 작업 명령(json 등)을 로봇 시스템에 전송한다.
2. AMR Adapter Node ACS 명령을 수신한다.
3. 수신된 명령을 파싱하여 내부 메시지로 변환한 뒤 `/robot/task_from_acs` 토픽으로 발행한다.
4. Schedular Node는 해당 명령을 큐에 등록하고 실행 준비를 한다.
5. 명령 수신 결과를 상태 토픽 또는 로그로 출력한다.

---

## 예외 흐름

- **E1: 명령 형식 오류**  
  → “작업 ID 누락” 또는 JSON 포맷 오류 등  
  → 요청 거부 및 오류 응답 반환

- **E2: 수신 시간 초과**  
  → 네트워크 지연 또는 비정상 연결  
  → 로그에 오류 기록, UI에는 상태 비정상 표시 가능

---

## 통신 흐름

| 송신자 | 수신자 | 방식 | 메시지 |
|--------|--------|------|--------|
| ACS | AMR Adapter Node | TCP Socket | 작업 명령 메시지 (json 등) |
| AMR Adapter Node | ROS2 | ROS2 Topic | `/robot/task_from_acs` |
| Schedular Node | 내부 큐 | 로컬 처리 | 작업 등록 및 실행 준비 |
| Status Node | FastAPI | ROS2 Topic | `/robot/status` (작업 대기 중 등) |

---

## 비고

- 향후 명령 형식은 공통 메시지 스펙(JSON, Protobuf 등)으로 정의 필요
- 보안 고려: 인증 키, 토큰, IP 화이트리스트 등을 활용한 안전한 통신 설계 필요
- 수신된 명령은 로그 및 이력 DB에 저장 권장
