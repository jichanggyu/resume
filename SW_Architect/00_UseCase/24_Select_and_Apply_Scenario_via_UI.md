# UC24 – 시나리오 선택 및 적용 (Select and Apply Scenario via UI)

## 개요

| 항목 | 내용 |
|------|------|
| **유즈케이스 ID** | UC24 |
| **유즈케이스 명** | 시나리오 선택 및 적용 |
| **관련 기능 요구사항** | SR6. 웹 기반 제어 UI 제공 |
| **주 액터** | 운영자 (Web UI 사용자) |
| **목적** | 운영자가 UI를 통해 미리 정의된 작업 시나리오를 선택하고 로봇에 적용할 수 있도록 한다. |

---

## 사전 조건

- 시스템에 하나 이상의 작업 시나리오(JSON, YAML 등 형식)가 등록되어 있어야 한다.
- 로봇은 “대기” 상태여야 하며, 작업 수행 중에는 시나리오 전환이 제한될 수 있다.

## 후 조건

- 선택한 시나리오가 적용되어 ROS2 제어 노드에 전달되고, 이후 작업은 해당 시나리오 기준으로 수행된다.

---

## 기본 흐름

1. Web UI에 등록된 시나리오 리스트를 표시한다.
2. 사용자가 시나리오를 선택하고 [적용] 버튼을 누른다.
3. Web UI는 FastAPI에 `/api/robot/scenario/apply` 요청을 전송한다.
4. FastAPI는 선택된 시나리오 ID를 `/robot/scenario_apply` 토픽으로 ROS에 전달한다.
5. `Schedular Node`는 해당 시나리오를 로딩하고, 내부 상태를 갱신한다.
6. 적용 결과가 FastAPI를 통해 UI에 전달된다.

---

## 예외 흐름

- **E1: 시나리오 파일 없음**  
  선택한 시나리오가 삭제되었거나 손상된 경우  
  → “시나리오 로드 실패” 메시지 표시

- **E2: 전환 중 상태 오류**  
  로봇이 작업 중이거나 멈출 수 없는 상태일 경우  
  → “작업 중에는 전환 불가” 경고 표시

---

## 통신 흐름

| 송신자 | 수신자 | 방식 | 메시지 |
|--------|--------|------|--------|
| Web UI | FastAPI | HTTP POST | `/api/robot/scenario/apply` |
| FastAPI | ROS2 | ROS2 Topic | `/robot/scenario_apply` (시나리오 ID) |
| Schedular Node | Status Node | 내부 처리 | 시나리오 적용 완료 상태 |
| Status Node | FastAPI | ROS2 Topic | `/robot/status` |
| FastAPI | Web UI | WebSocket or 응답 | 적용 결과 표시 |

---

## 비고

- 시나리오에는 작업 순서, 조건 분기, 대기 시간 등이 포함될 수 있음
- UI에서는 시나리오 미리보기, 편집, 삭제 기능도 추후 확장 가능
- 시스템은 적용된 시나리오 이력을 기록하고, 재사용할 수 있도록 구성 필요
