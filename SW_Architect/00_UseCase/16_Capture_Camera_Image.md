# UC16 – 카메라 이미지 입력 (Capture Camera Image)

## 개요

| 항목 | 내용 |
|------|------|
| **유즈케이스 ID** | UC16 |
| **유즈케이스 명** | 카메라 이미지 입력 |
| **관련 기능 요구사항** | F6-1. 카메라 이미지 입력 |
| **주 액터** | 로봇 제어 노드 (ROS2 내부 액터) |
| **목적** | 로봇이 파지점을 판단하기 위해 실시간 카메라 이미지를 획득한다. |

---

## 사전 조건

- 카메라(3D 또는 2D)가 연결되어 있고 정상적으로 작동 중이어야 한다.
- 카메라 이미지 스트림 또는 요청 기반 프레임 캡처가 가능해야 한다.

## 후 조건

- 실시간 이미지 데이터가 ROS2로 전달되고, 비전 노드에서 처리할 수 있는 상태가 된다.

---

## 기본 흐름

1. 카메라 드라이버 또는 센서 노드가 실시간 이미지 프레임을 `/camera/image_raw` 등의 토픽으로 publish한다.
2. Vision Node는 해당 토픽을 구독(subscribe)하여 이미지를 수신한다.
3. 수신된 이미지는 내부 처리 큐에 적재되거나 즉시 후속 프로세싱(특징점 추출 등)에 사용된다.
4. 필요 시, Vision Node는 수신된 이미지를 로그 저장하거나 디버깅용으로 publish한다.

---

## 예외 흐름

- **E1: 카메라 미연결 / 초기화 실패**  
  → “카메라 연결 오류” 또는 “센서 초기화 실패” 로그 출력 및 UI 경고

- **E2: 프레임 수신 지연**  
  일정 시간 이상 프레임 수신 실패 시  
  → “이미지 수신 시간 초과” 경고 출력 및 재시도

---

## 통신 흐름

| 송신자 | 수신자 | 방식 | 메시지 |
|--------|--------|------|--------|
| camera driver | ROS2 Topic | `/camera/image_raw` (sensor_msgs/Image) |
| Vision Node | 내부 처리 | 이미지 프레임 수신 및 저장 또는 처리 |

---

## 비고

- 카메라 노드는 Intel RealSense, ZED, USB 웹캠 등 다양한 종류에 따라 달라질 수 있음
- 캡처 해상도, FPS 등은 설정 가능한 파라미터로 관리
- 이후 단계(특징점 추출)와 비동기 또는 동기 방식 연계 가능
