# UC17 – 특징점 추출 (Feature Point Extraction)

## 개요

| 항목 | 내용 |
|------|------|
| **유즈케이스 ID** | UC17 |
| **유즈케이스 명** | 특징점 추출 |
| **관련 기능 요구사항** | F6-2. 특징점 추출 |
| **주 액터** | 비전 노드 (ROS2 내부 액터) |
| **목적** | 카메라 이미지로부터 물체의 윤곽, 모서리, 홀 등 특징점을 검출한다. |

---

## 사전 조건

- 비전 노드는 이미지 입력을 정상적으로 수신해야 한다.
- 이미지 해상도 및 포맷이 사전 정의된 조건과 일치해야 한다.

## 후 조건

- 이미지 내에서 검출된 특징점 리스트가 생성되고, 이후 파지 후보 영역 계산에 전달된다.

---

## 기본 흐름

1. Vision Node는 `/camera/image_raw`로부터 이미지를 수신한다.
2. 이미지 프레임이 입력되면 내부 특징점 추출 알고리즘을 실행한다.
3. 특징점(좌표, 방향, 스케일 등)이 추출된다.
4. 추출된 특징점은 내부에서 보관되며, 필요 시 `/vision/feature_points` 토픽으로 publish된다.
5. 이후 UC18(파지점 계산)에 입력으로 사용된다.

---

## 예외 흐름

- **E1: 이미지 포맷 오류**  
  입력 이미지가 처리 불가능한 해상도/채널 구조일 경우  
  → "이미지 처리 실패: 포맷 오류" 로그 및 예외 처리

- **E2: 특징점 없음**  
  특징점이 충분히 검출되지 않거나 noise만 존재할 경우  
  → “유효한 특징 없음” 경고 메시지 출력

---

## 통신 흐름

| 송신자 | 수신자 | 방식 | 메시지 |
|--------|--------|------|--------|
| camera driver | Vision Node | ROS2 Topic | `/camera/image_raw` (sensor_msgs/Image) |
| Vision Node | 내부 알고리즘 | 로컬 호출 | 특징점 추출 처리 |
| Vision Node | ROS2 | ROS2 Topic (선택) | `/vision/feature_points` (custom msg 또는 geometry_msgs) |


---

## 비고

- 특징점 유형은 프로젝트 요구에 따라 다르게 설정 가능  
  (예: 흡착 대상이면 평면성/원형 홀 위주, 집기 대상이면 외곽 윤곽 위주)
- 추출 신뢰도(score) 기반으로 필터링하여 품질 보장
- 특징점은 다음 단계인 파지 후보 계산에 직접 활용됨
