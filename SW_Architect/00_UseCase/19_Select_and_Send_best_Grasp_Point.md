# UC19 – 최적 파지점 선정 및 전달 (Select and Send Best Grasp Point)

## 개요

| 항목 | 내용 |
|------|------|
| **유즈케이스 ID** | UC19 |
| **유즈케이스 명** | 최적 파지점 선정 및 전달 |
| **관련 기능 요구사항** | F6-4. 최적 파지점 선정 및 전달 |
| **주 액터** | 비전 노드 (ROS2 내부 액터) |
| **목적** | 생성된 파지 후보 중에서 가장 적절한 파지점을 선정하고 제어 노드에 전달한다. |

---

## 사전 조건

- 파지 후보 리스트가 유효하게 생성되어 있어야 한다.
- 파지점 평가 기준(신뢰도, 안정성, 충돌 가능성 등)이 정의되어 있어야 한다.
- ROS2 제어 노드가 파지점 메시지를 수신할 준비가 되어 있어야 한다.

## 후 조건

- 최적의 파지점(6D pose)이 선정되어 ROS2 제어 노드로 전달된다.
- 해당 파지점이 실제 Pick 동작의 기준으로 사용된다.

---

## 기본 흐름

1. Vision Node는 grasp 후보 리스트를 입력으로 받는다.
2. 내부 평가 알고리즘(규칙 기반 또는 ML 기반)을 사용하여 각 후보를 점수화한다.
3. 가장 점수가 높은 후보를 최적 파지점으로 선택한다.
4. 선택된 grasp pose는 내부 저장 또는 `/vision/best_grasp_pose` 토픽으로 publish된다.
5. Command Executor Node는 이 토픽을 구독하거나 service 요청을 통해 값을 수신한다.

---

## 예외 흐름

- **E1: 유효한 파지점 없음**  
  후보가 없거나 모두 점수가 기준 이하일 경우  
  → “파지점 선택 실패” 메시지를 상위에 전달

- **E2: 메시지 발행 실패**  
  ROS2 토픽 전송 중 에러 발생  
  → 로그 기록 및 재시도 수행

---

## 통신 흐름

| 송신자 | 수신자 | 방식 | 메시지 |
|--------|--------|------|--------|
| Vision Node | 내부 알고리즘 | 로컬 호출 | 최적 파지점 평가 |
| Vision Node | ROS2 Topic or Service | `/vision/best_grasp_pose` (geometry_msgs/PoseStamped 또는 custom) |
| Command Executor Node | Vision Node | ROS2 Service or Subscribe | 최적 파지점 수신 요청 또는 구독 |


---

## 비고

- 최적 파지점 선정 알고리즘은 프로젝트 목적에 따라 가중치 조정 가능
- 메시지에 평가 score를 포함하면 실패 시 백업 파지점 사용 가능
- 시각 디버깅용 시뮬레이터와 연계 시 시각적으로 파지점 표시 가능
