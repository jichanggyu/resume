# UC07 – 통신 상태 표시 (Display Communication Status)

## 개요

| 항목 | 내용 |
|------|------|
| **유즈케이스 ID** | UC07 |
| **유즈케이스 명** | 통신 상태 표시 |
| **관련 기능 요구사항** | F2-4. 통신 상태 표시 |
| **주 액터** | 운영자 (Web UI 사용자) |
| **목적** | 로봇과 각 구성 요소(ROS2 노드, FastAPI, 센서 등)의 통신 연결 상태를 실시간으로 확인한다. |

---

## 사전 조건

- 각 구성 요소는 일정 주기로 “상태 alive/ping 메시지”를 발행해야 한다.
- 백엔드에서는 각 노드나 모듈과의 연결 상태를 주기적으로 확인해야 한다.

## 후 조건

- UI에서 각 노드 및 주요 구성요소의 연결 상태(정상/끊김)를 확인할 수 있다.
- 통신 장애 발생 시 즉시 경고 메시지가 표시된다.

---

## 기본 흐름

1. `Status Node` 또는 FastAPI는 ROS2 노드들과의 상태 heartbeat 또는 주기적 토픽 수신 여부를 모니터링한다.
2. 일정 시간 내 상태 메시지가 도착하지 않으면 `"끊김"` 상태로 간주한다.
3. FastAPI는 현재 연결 상태(정상/끊김)를 WebSocket 또는 응답 API로 UI에 전달한다.
4. Web UI는 연결 상태를 색상/아이콘/텍스트 등으로 시각화한다.
---

## 예외 흐름

- **E1: 특정 노드 미응답**  
  특정 ROS2 노드가 일정 시간 이상 상태 메시지를 발행하지 않는 경우  
  → UI에 “Node 응답 없음” 또는 “통신 끊김” 표시

- **E2: FastAPI ↔ ROS 연결 오류**  
  내부 bridge 또는 통신 라우팅에 문제가 발생한 경우  
  → 모든 구성 요소에 대해 “통신 장애” 상태 표시

---

## 통신 흐름

| 송신자 | 수신자 | 방식 | 메시지 |
|--------|--------|------|--------|
| ROS2 각 노드 | Status Node | ROS2 Topic | 상태 heartbeat 또는 ping |
| Status Node | FastAPI | 내부 모니터링 | 통신 상태 판단 결과 전달 |
| FastAPI | Web UI | WebSocket or REST | `"정상"`, `"끊김"`, `"지연"` 등의 상태 전달 |
| Web UI | 화면 표시 | 시각화 | 연결 상태 표시 아이콘, 컬러 상태 등 |

---

## 비고

- 연결 상태는 UI 상단 또는 별도 “시스템 상태” 영역에서 표시하는 것이 일반적
- 응답 시간 기준 예: 2초 이상 미응답 시 “끊김” 표시, 다시 수신되면 자동 회복
- 향후 알림 시스템과 연계하여 관리자에게 즉시 알림 전송 가능
