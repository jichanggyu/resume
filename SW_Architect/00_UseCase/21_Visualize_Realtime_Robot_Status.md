# UC21 – 실시간 상태 정보 시각화 (Visualize Realtime Robot Status)

## 개요

| 항목 | 내용 |
|------|------|
| **유즈케이스 ID** | UC21 |
| **유즈케이스 명** | 실시간 상태 정보 시각화 |
| **관련 기능 요구사항** | SR6. 웹 기반 제어 UI 제공 |
| **주 액터** | 운영자 (Web UI 사용자) |
| **목적** | 웹 UI를 통해 로봇의 현재 위치, 상태, 배터리, 동작 정보를 실시간으로 시각화한다. |

---

## 사전 조건

- ROS2에서 주기적으로 상태 정보(위치, 작업 상태, 배터리 등)를 발행해야 한다.
- FastAPI가 이를 WebSocket 또는 REST API로 전달할 수 있어야 한다.
- 웹 UI는 상태 수신 후 즉시 시각화할 수 있어야 한다.

## 후 조건

- 운영자는 웹 페이지에서 로봇의 현재 상태를 직관적으로 확인할 수 있다.

---

## 기본 흐름

1. `status_node`는 로봇의 위치 정보를 `/robot/pose` 토픽으로 주기적으로 publish한다.
2. FastAPI는 해당 토픽을 구독하여 최신 pose 데이터를 수신한다.
3. Web UI는 FastAPI로부터 pose 데이터를 실시간으로 수신한다.
4. UI는 이를 기반으로 위치 좌표(x, y, z)와 자세(rx, ry, rz)를 텍스트 또는 그래픽(2D/3D)으로 시각화한다.

---

## 예외 흐름

- **E1: 상태 수신 불가**  
  일정 시간 이상 ROS2 또는 FastAPI로부터 데이터 수신 실패  
  → “상태 정보 수신 중단” 경고 표시

- **E2: 값 이상 탐지**  
  예: 배터리 값 110%, 좌표 NaN 등  
  → “이상 데이터 감지됨” 경고 및 내부 로그 기록

---

## 통신 흐름

| 송신자 | 수신자 | 방식 | 메시지 |
|--------|--------|------|--------|
| Status Node | ROS2 Topic | /robot/pose(geometry_msgs/PoseStamped) | - |
| Fast API | Web UI | WebSocket or Rest | Pose 데이터 전달 |
| Web UI | UI 표시 | 시각화 컴포넌트 | 좌표 텍스트, 지도, 3D 모델 등 표시 |

---

## 비고

- 위치 정보는 2D 또는 3D 시각화로 표현 가능 (예: 좌표 표시, AGV 아이콘 위치 등)
- 배터리는 게이지, 작업 상태는 아이콘/컬러 변경 등으로 직관적 표현 필요
- UI 성능 최적화를 위해 데이터 수신 간격은 0.5~1초 추천
