# UC23 – 알람 및 에러 상태 알림 표시 (Alarm and Error Notification via UI)

## 개요

| 항목 | 내용 |
|------|------|
| **유즈케이스 ID** | UC23 |
| **유즈케이스 명** | 알람 및 에러 상태 알림 표시 |
| **관련 기능 요구사항** | SR6. 웹 기반 제어 UI 제공 |
| **주 액터** | 운영자 (Web UI 사용자) |
| **목적** | 로봇의 상태에서 발생하는 오류 및 경고 정보를 사용자에게 즉시 전달하고, 확인 및 조치할 수 있도록 한다. |

---

## 사전 조건

- ROS2 각 노드 또는 센서에서 알람/에러 상태 메시지를 발행해야 한다.
- FastAPI가 상태 메시지를 수신하고 웹 UI에 전달할 수 있어야 한다.

## 후 조건

- UI에 에러 또는 경고 발생 시 실시간으로 알림이 표시된다.
- 사용자는 알림 내역을 확인하고 대응할 수 있다.

---

## 기본 흐름

1. `Status Node`, `Safety Interlock Node`, 또는 기타 하드웨어 노드가 에러 또는 알람 상태를 감지한다.
2. 해당 알람 상태가 `/robot/alert` 토픽으로 publish된다. (예: `"충돌 위험"`, `"E-stop 발생"` 등)
3. FastAPI는 이 토픽을 구독하고 알람 상태를 수신한다.
4. FastAPI는 WebSocket 또는 알림 전용 API를 통해 UI로 상태를 전송한다.
5. Web UI는 해당 알림을 배너, 팝업, 또는 로그 알림 영역에 즉시 표시한다.

---

## 예외 흐름

- **E1: 알람 메시지 누락**  
  ROS2 메시지가 손실되거나 전달되지 않으면  
  → “알람 수신 실패” 로그 기록 (UI에는 표시 안 됨)

- **E2: 알람 중복 또는 연속 발생**  
  동일한 알람이 반복적으로 발생할 경우  
  → UI에 묶음으로 표시하거나 축약 표기 처리

---

## 통신 흐름

| 송신자 | 수신자 | 방식 | 메시지 |
|--------|--------|------|--------|
| Safety Interlock Node, Status Node | ROS2 Topic | `/robot/alert` (std_msgs/String 또는 custom AlertMsg) |
| FastAPI | Web UI | WebSocket or REST | 알림 메시지 전달 |
| Web UI | 사용자 | UI 컴포넌트 | 배너, 팝업, 로그 등 알림 표시 |

---

## 비고

- 알람 유형: 경고(Warning), 오류(Error), 긴급(Emergency) 등으로 구분 가능
- 알림 내역은 로그 파일 또는 DB에 저장되어 이력 조회 가능
- 알림 해제 또는 복구 메시지도 함께 처리되어야 함
