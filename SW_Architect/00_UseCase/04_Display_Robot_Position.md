# UC04 – 로봇 위치 정보 표시 (Display Robot Position)

## 개요

| 항목 | 내용 |
|------|------|
| **유즈케이스 ID** | UC04 |
| **유즈케이스 명** | 로봇 위치 정보 표시 |
| **관련 기능 요구사항** | F2-1. 로봇 위치 정보 표시 |
| **주 액터** | 운영자 (Web UI 사용자) |
| **목적** | 로봇의 현재 위치 및 자세(Pose)를 실시간으로 확인한다. |

---

## 사전 조건

- 로봇은 ROS2에서 현재 pose(x, y, z, rx, ry, rz)를 주기적으로 브로드캐스트해야 한다.
- 웹 UI는 실시간 위치 정보를 구독하거나 갱신할 수 있어야 한다.

## 후 조건

- 운영자는 로봇의 실시간 위치(Pose)를 UI 상에서 확인할 수 있다.
- UI에는 숫자 값 또는 시각화된 형태로 위치가 표현된다.

---

## 기본 흐름

1. `Status Node`는 로봇의 현재 위치(x, y, z, rx, ry, rz)를 주기적으로 계산한다.
2. 해당 위치 정보를 ROS2 토픽(`/robot/pose`)으로 publish한다.
3. FastAPI는 이 토픽을 구독하여 실시간으로 수신한다.
4. FastAPI는 수신된 pose 데이터를 WebSocket 또는 API 응답을 통해 Web UI에 전달한다.
5. Web UI는 좌표 및 자세 정보를 표시한다 (텍스트, 지도, 3D 뷰 등).

---

## 예외 흐름

- **E1: ROS 위치 데이터 수신 실패**  
  ROS2에서 pose 데이터를 수신하지 못한 경우  
  → UI에 “위치 정보를 수신할 수 없습니다” 경고 표시

- **E2: UI 연결 끊김**  
  네트워크 문제로 위치 정보 수신 불가  
  → UI에 자동 재연결 시도 표시 또는 “연결 끊김” 알림 표시

---

## 통신 흐름

| 송신자 | 수신자 | 방식 | 메시지 |
|--------|--------|------|--------|
| Status Node | ROS2 | ROS2 Topic | `/robot/pose` (PoseStamped 또는 Pose) |
| FastAPI | Web UI | WebSocket or REST API | 실시간 pose 데이터 전송 |
| Web UI | 화면 | 시각화 | 위치 텍스트, 지도, 3D 모델 등 표시 |

## 비고

- 위치 정보는 단순 텍스트 표시 외에도 WebGL 또는 2D Canvas를 통한 시각화가 권장된다.
- 데이터가 1초 이상 끊길 경우 UI 경고 메시지를 표시하도록 설계 필요.
