# UC22 – 작업 순서/흐름 설정 UI 제공 (Task Flow Configuration via UI)

## 개요

| 항목 | 내용 |
|------|------|
| **유즈케이스 ID** | UC22 |
| **유즈케이스 명** | 작업 순서/흐름 설정 UI 제공 |
| **관련 기능 요구사항** | SR6. 웹 기반 제어 UI 제공 |
| **주 액터** | 운영자 (Web UI 사용자) |
| **목적** | 웹 UI에서 로봇의 작업 순서를 확인하고, 사용자 지정 흐름으로 수정/적용할 수 있도록 한다. |

---

## 사전 조건

- 시스템에 하나 이상의 기본 시나리오 또는 작업 리스트가 정의되어 있어야 한다.
- 로봇이 작업 대기 중이거나 특정 작업 중에는 순서 변경을 제한해야 한다.

## 후 조건

- 운영자가 UI를 통해 작업 흐름을 확인하고, 사용자 정의 순서로 변경/저장할 수 있다.
- 저장된 순서는 ROS2 제어 노드에 전달되어 반영된다.

---

## 기본 흐름

1. Schedular Node는 현재 로딩된 시나리오 단계 리스트와 현재 수행 중인 작업 인덱스를 보유한다.
2. 해당 정보를 `/robot/scenario_flow` 또는 `/robot/task_status` 토픽으로 publish한다.
3. FastAPI는 이를 구독하고 Web UI로 전달한다.
4. Web UI는 전체 시나리오 단계를 순서대로 표시하며, 현재 수행 중인 작업을 강조한다.
   - 예: Step 1: Pick → **Step 2: Place (진행 중)** → Step 3: Door Close

---

## 예외 흐름

- **E1: 진행 중 작업 포함**  
  현재 수행 중인 작업은 순서 변경 대상에서 제외되어야 함  
  → UI에 “진행 중 작업은 수정 불가” 메시지 표시

- **E2: 잘못된 작업 ID 포함**  
  정의되지 않은 작업 ID가 포함되어 있거나 중복된 경우  
  → “작업 리스트 오류” 경고 및 되돌리기 제공

---

## 통신 흐름

| 송신자 | 수신자 | 방식 | 메시지 |
|--------|--------|------|--------|
| Schedular Node | ROS2 Topic | `/robot/scenario_flow` (custom msg: 전체 리스트 + 현재 index) |
| FastAPI | Web UI | WebSocket or REST | 시나리오 단계 리스트 및 상태 전달 |
| Web UI | UI 컴포넌트 | 시각화 | 단계 리스트, 현재 위치 강조 표시 등 |

---

## 비고

- UI는 작업 순서를 시각적으로 편집 가능해야 하며, "적용", "초기화", "취소" 버튼 필요
- 각 작업의 설명 또는 아이콘 표시를 통해 직관적인 편집을 지원
- 작업 순서 변경 이력은 로그로 저장될 수 있음 (예: 관리자 추적용)
